# Feature Description

## Overview
This project investigates the relationship between student engagement and final module marks using routinely collected institutional data. The study focuses on whether engagement indicators are associated with academic performance and whether these indicators can help identify patterns of success or risk.

The engagement measures used in this project are drawn from two university systems:

- **Blackboard Ultra**: Used to obtain student activity data such as hours spent in the course.
- **SEAtS**: Used to obtain attendance records for:
    - Lectures
    - Workshops
    - Feedback sessions

The main research question is:
**How does student engagement relate to the final mark in a module?**

To address this, the project combines engagement data and assessment outcomes into a single student-level dataset. Each student record includes:
- Final module mark (numeric)
- Hours spent in the Blackboard course
- overall attendance percentage 
- Lecture attendance percentage
- Workshop attendance percentage
- Feedback attendance percentage

### Key Features
- Blackboard “hours in course”
- overall attendance percentage
- lecture attendance rate
- workshop attendance rate
- feedback attendance rate

### Outcom   
- final numeric module mark

**The analysis is designed to examine:**
- Whether students with higher engagement tend to achieve higher final marks.
- Which type of engagement shows the strongest relationship with performance.
- Whether engagement can be used as an early indicator of academic outcomes.
